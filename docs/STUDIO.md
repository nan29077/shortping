# 숏핑 스튜디오 (AI 제작) · 라마 · 업로드 고도화

PD는 두 가지 방법으로 작품을 만들고, 어느 쪽이든 **같은 검수 절차**를 거쳐 공개합니다.

```
새 작품 만들기 ─┬─ 직접 업로드 (외부 제작 영상) ─────────┐
                └─ 숏핑 스튜디오 (AI 제작) → 내보내기 ──┴→ 작품·회차 → 검수 신청 → 관리자 검수 → 공개
```

## 1. 직접 업로드 고도화

- **여러 회차 한 번에 올리기**: 파일 이름("03화", "EP03", "episode-3", "3.mp4")으로 회차를 인식. 회당 최대 500MB.
- **분할·이어 올리기**: 8MB 조각으로 전송(`POST /api/studio/uploads` → `PUT ?offset=` → `POST /complete`). 끊기면 서버가 받은 위치부터 이어 올림. 하루 넘게 멈춘 조각은 자동 정리.
- **자동 사전 점검**(경고, 반려 아님): 가로 영상·9:16 아님·720p 미만·15초 미만·3분 초과·소리 없음.
- **포스터 후보**: 영상에서 장면 3장 추출 → 골라서 포스터로.
- **자막**: SRT/VTT 업로드 → 태그를 지운 WebVTT로 저장, 시청 권한이 있는 사람만 `/api/subtitles/:id/:n`으로 받음. 시청 화면·검수 화면에 자막 트랙 표시.
- **권리·AI 자가 신고**: 권리 보유 확인(심사 요청 필수), 초상권 동의, 생성형 AI 사용(없음/일부/대부분). AI를 쓴 작품은 시청 화면에 ‘AI 제작’ 표시.
- **검수 화면**: 제작 출처(업로드/AI/혼합), 권리·초상권, AI 신고, 자막 수, 회차별 점검 경고, 스튜디오 제작 이력(사용한 모델·공급사·국가).
- **업로드 영상용 AI 도구**(라마 사용): AI 자동 자막(음성 인식), AI 포스터 후보.

## 2. 라마 (제작 포인트)

| 항목 | 내용 |
| ---- | ---- |
| 단위 | 1라마 = 10원 |
| 충전 | PD 스튜디오(웹) 전용 상품. 기본 1만/5만(+250)/10만(+700)/30만(+3,000). 관리자가 상품·보너스 수정 |
| 체험 | PD가 처음 스튜디오를 열면 체험 라마(기본 300) 1회 지급 |

## 3. AI 연결 (슈퍼관리자)

- **공급사 종류(어댑터)**: OpenAI(“Astra” 등 OpenAI 모델은 모델 ID만 입력), OpenAI 호환(DeepSeek·Qwen·Kimi·GLM·Doubao 등), Anthropic Claude, Google Gemini·Veo, fal.ai·Replicate(Kling·Seedance·Hailuo·Wan·FLUX·Seedream 중계), ElevenLabs, Kling 직접, MiniMax(Hailuo·음성), Alibaba DashScope(Wan), ByteDance Ark(Seedance·Seedream).
- **프리셋**: 공급사+추천 모델을 한 번에 추가(키는 이후 입력). 모델 ID·가격은 2026년 7월 공개 자료 기준 참고값이므로 공급사 문서로 확인 후 수정.
- **API 키 보안**: AES-256-GCM 암호화 저장, 화면에는 끝 4자리만. 운영에서는 `AI_SECRET_KEY` 환경변수 **필수**(개발은 데이터 폴더의 키 파일 자동 생성). 기본 주소(base URL)로 지역 엔드포인트·프록시 지정 가능. 연결 테스트 버튼.
- **가격**: 모델별 원가(USD/단위) × 환율 × 마진% ÷ 10원 = 라마 단가, 또는 고정 라마 단가. 단위: 글 1천 토큰 · 이미지 1장 · 영상 1초 · 음성 1천 자 · 자막 1분.
- **자동 선택**: 품질 등급(초안/표준/고급) → 장면 태그(대사·클로즈업·액션·풍경…) → 관리자 우선순위 → 가격 순으로 점수. 실패 시 예약 라마 안에서 다음 모델로 자동 전환(최대 3회), 직접 선택은 같은 모델로 재시도.
- **비용 통제**: AI 제작 켜기/끄기, 플랫폼 월 AI 원가 한도, PD 하루 한도(공통 + PD별 하루/월 한도·이용 제한), 동시 작업 수, 금칙어(기본: 딥페이크·실존 인물·미성년 선정성 등 + 관리자 추가).
- **작업 모니터**: 상태·모델·재시도·라마·원가, 대기/멈춘 작업 취소 시 전액 환불. **모델 시험**(라마 미차감, 플랫폼 원가).
- **중국 모델 통제**: 정책 탭의 ‘중국 AI 모델 사용 허용’을 끄면 PD 선택 목록·자동 선택·대체 모델에서 모두 빠짐. PD는 프로젝트마다 ‘중국 모델 쓰지 않기’ 가능(직접 선택해도 거절).
- **라우팅 규칙**: 작업(글·이미지·음성·영상) × 품질 등급별로 먼저 쓸 모델 순서(최대 10개)를 지정. 규칙이 없으면 자동 점수.
- **공급사 안정장치**: 공급사별 동시 작업 수·월 원가 한도(초과 시 자동 제외), 연속 실패 N회 또는 키 거부(401) 시 설정한 시간 동안 자동 제외(서킷 브레이커) → ‘되살리기’ 버튼. ‘모델 불러오기’로 공급사 API의 모델 ID 목록을 받아 원가만 넣고 바로 등록.
- **가격 일괄 조정**: 작업별/전체 모델을 자동 계산으로 되돌리거나 현재 가격 × 배율로 고정.
- **분석·모니터**: 일별 원가·라마 매출 차트(7/30/90일), 모델별 성공률·평균 소요·재시도, 전체 PD 프로젝트 모니터(진행·라마·원가·자동 제작 상태), 금칙어에 막힌 요청 ‘안전 기록’.
- **개발용 가짜 AI**: 개발 환경(demo)에서만 등록. 키 없이 전 과정을 끝까지 돌려 보고 테스트할 수 있음. 운영에서는 선택 목록에 나오지 않음.

## 4. 숏핑 스튜디오 제작 과정 (PD)

1. **이용 약관 동의**: 결과물 저작권은 PD, 숏핑은 서비스·홍보 목적 무상 이용권 / 해외·중국 AI 공급사로 입력 전송 고지 / AI 제작 표시·검수 / 금지 콘텐츠 / 라마 예약·반환.
2. **기획**: 한 줄 아이디어·장르·분위기·회차 수·회당 길이 → AI 기획안(제목·줄거리·스타일·인물·회차 구성). 다시 만들어도 이미지를 만든 인물과 대본이 있는 회차는 보존.
3. **캐릭터**: 인물별 외모(영어)·성격·목소리 모델/ID, 기준 이미지 생성(이후 스토리보드에 참고 이미지로 전달해 얼굴 일관성 유지).
4. **대본**: 회차별 컷(장면·화면 묘사(영어)·대사·화자·카메라·길이) 생성, 편집·순서 변경·추가·삭제.
5. **스토리보드·음성**: 컷 이미지, 대사 음성(TTS) — 개별 또는 ‘빈 컷 모두’.
6. **영상**: 컷 영상(스토리보드 이미지에서 시작), 자동 선택은 대사 클로즈업/액션/초안에 맞는 모델.
7. **합성·포스터**: 컷 영상(없으면 스토리보드 이미지 모션)과 음성을 컷 길이에 맞춰 붙여 720×1280 H.264/AAC MP4 + WebVTT 자막 생성(라마 없음). AI 포스터 또는 인물·스토리보드 이미지 선택.
8. **내보내기·검수**: 합성된 회차를 작품의 회차로 등록(`episodes.source='studio'`, AI 제작 표시 자동), 바로 검수 신청 가능. 반려되면 수정해 다시 내보내기.

**편의 기능(PD)**
- **새 프로젝트 마법사**: 장르 템플릿 18종 또는 직접 쓰기 → 영상 스타일 칩 8종 → 중국 모델 제외 선택. 계약·재회·궁중 로맨스, 복수·미스터리·수사·반전극, 회귀·타임루프·중세·SF, 학원·힐링·음악·스포츠, 오피스·동거·반려동물 코미디를 제공하며 검색과 장르 필터를 지원합니다. 기본 이모지 대신 숏핑 UI와 같은 선 굵기의 장르별 컬러 아이콘을 사용합니다.
- **초보 PD 시작 화면**: 30초 1화로 시작, 완성 영상 등록, 제작 가이드 진입을 분리했습니다. 프로젝트 제목·아이디어·장르 검색, 제작 상태 필터, 최근 수정순·제목순 정렬을 제공합니다.
- **제작 가이드**: 9개 챕터 검색, 복사 가능한 예시, 단계별 설명, 자주 묻는 질문과 공개 전 연습 체크리스트. 체크리스트는 임시 확인용이며 실제 권리 확인·검수 신청을 대체하지 않습니다.
- **단계별 안내**: 기본 안내 모드, 현재 단계의 할 일, 상세 가이드 팝업, 이전·다음 단계 이동과 회차별 진행 상태를 제공합니다. 고급 모델 선택과 자동 제작 설정은 필요할 때 펼칩니다. 기획 수정 중 단계·프로젝트 목록 이동 시 미저장 경고를 표시하고 새로고침·창 닫기에도 경고합니다. 다른 메뉴로의 이동과 캐릭터·컷 편집은 각 저장 버튼을 사용해야 합니다.
- **진행률 · 다음 할 일**: 작업공간 상단에 완성 %와 다음에 할 단계 바로가기, 단계 탭마다 완료/개수 표시.
- **자동 제작(오토파일럿)**: 모델·품질·영상 포함 여부·최대 라마를 정하면 기획→인물→대본→스토리보드→음성→(영상)→합성까지 빈 곳만 채움. 단계별 예상 라마 표를 먼저 보여 주고, 최대 라마를 넘거나 같은 단계가 두 번 실패하면 멈춰 이유를 알려 줌. 멈추기 시 대기 작업 취소·환불. 화면을 닫아도 서버에서 계속 진행.
- **회차 미리보기**: 합성 전에도 컷 영상(없으면 스토리보드 이미지 모션)+대사 음성+자막을 이어 재생(라마 없음, 스페이스/←→/Esc).
- **컷 AI로 고치기**: “더 긴장감 있게” 등 칩이나 직접 쓴 요청으로 그 컷의 장면·화면·대사만 다시 씀.
- **목소리 미리듣기**: 인물별 목소리 샘플 생성, 공급사별 목소리 ID 추천 목록.
- **비용 내역**: 내보내기 단계에서 작업 종류별 라마·실패(반환) 내역. 스튜디오 상단에 진행 중 AI 작업·자동 제작 표시, PD 대시보드에 최근 프로젝트 카드.

모든 결과는 **버전**으로 남아 이전 이미지·음성·영상으로 되돌릴 수 있습니다. 실행 전에는 항상 **예상 라마**를 보여 주고 확인을 받습니다.

## 6. 운영 전 필요한 것

1. `AI_SECRET_KEY` 환경변수(32자 이상 임의 문자열) 설정 후 공급사 API 키 입력.
2. 각 공급사 모델 ID·가격을 최신 문서로 확인, 실제 키로 ‘연결 테스트’와 ‘시험’ 실행.
3. 작업 대기열은 지금 서버 프로세스 안에서 돕니다. 사용량이 늘면 별도 작업 프로세스(워커)로 분리하고, 결과 파일은 S3로 옮기는 것을 권장합니다.
4. 라마 충전은 테스트 결제입니다. PG 연동 시 핑과 같은 방식으로 결제 승인 확인 후 적립으로 바꿉니다.
5. 약관(결과물 권리, 해외·중국 전송 고지)과 AI 기본법 표시 의무는 법률 검토를 권합니다.

## 7. 관리자 연결 준비와 재시도 안정성

- AI 연결 관리의 첫 탭은 **연결 준비**입니다. 실제 공급사의 키·연결 확인·활성 모델·중국 허용 정책·장애 대기·예산 소진 상태를 확인하고 각 설정 메뉴로 이동할 수 있습니다. 개발용 모의 AI는 실제 공급사 집계에서 제외합니다.
- 작업별 모델 준비 상태, 운영 체크리스트, 공급사 검색·국가 필터, 새 AI 요청 허용·중국 모델 허용 스위치를 제공합니다. 연결 확인 표시는 등록 및 연결 테스트 기준이며 실제 생성 품질을 보증하지 않습니다.
- API 키는 추후 최고관리자가 입력합니다. 이번 개발·검증에는 유료 외부 AI 키를 등록하거나 실제 공급사 생성 API를 호출하지 않았습니다.
- 네트워크 재시도 시 동일한 요청 식별자를 유지합니다. 서버는 프로젝트 단위 트랜잭션 안에서 중복 요청·진행 작업을 확인하고 라마를 예약합니다. 같은 요청의 동시 전송 및 완료 후 재전송이 같은 작업을 반환하는 회귀 테스트를 포함합니다.
- 자동 테스트는 SQLite와 개발용 AI·로컬 공급사 에뮬레이터 기준입니다. PostgreSQL 및 실제 공급사의 모델 ID·단가·키 권한·영상 품질·지연 시간은 운영 연결 후 별도 확인해야 합니다.
