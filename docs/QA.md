# 숏핑 검증 기록

검증일: 2026-09-18. 환경: Windows, Node.js 24.19.0, 로컬 SQLite, Codex Chromium 브라우저.

## 자동 검증

- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- `npm test`: API 통합 테스트 **14개 통과, 실패 0개**. 테스트마다 별도 실행 디렉터리의 DB를 사용하고 운영 중인 로컬 데모 DB를 초기화하지 않음.
- 검증 내용: 공개 카탈로그, 회차 메타데이터, 무료 영상 HTTP Range, 유료 영상 무권한 차단, 원본 영상 직접 접근 차단, viewer/PD/admin 권한 경계, 회원가입 권한 강제, 비밀번호 로그인, HttpOnly 쿠키, 중복 이메일, cross-origin 요청 차단, 계정별 찜 격리, 시청 위치 저장, 금액 위조 무시, 동시 중복 구매 멱등성, 소장 권한, 구독·종료, PD 초안 비공개, 빈 작품 심사 차단, 업로드 파일 헤더 검증, 심사 반려·재제출·승인, 공개 후 수정 차단, 회원 역할 변경, 감사 기록, 로그아웃 후 세션 무효화.

## 브라우저 검증

- PC: 중앙 620px 앱 레이아웃, 좌측 생성형 포스터, 우측 앱 안내·마스코트, 로고, 로컬 한글 글꼴 확인.
- 모바일 390×844: 홈·썸네일 제목·가로 스크롤 목록·하단 메뉴·멤버십 화면을 시각 확인. document width 385px, viewport 390px로 페이지 가로 넘침 없음. 깨진 이미지 0개.
- 모바일 320×740: document width 320px, viewport 320px, 깨진 이미지 0개.
- 시청자 테스트 로그인 → 자정의 계약 찜 → 4화 잠금 → 3,900원 가상 구매 → 잠금 해제 및 영상 메타데이터 로딩 확인. 비디오 readyState 4, duration 12초.
- PD 테스트 로그인 → ‘너에게 닿는 시간’ 작성 → 1화 ‘멈춰 있던 시계’ 등록 → 심사 요청 확인.
- 관리자 테스트 로그인 → 작품 승인 → 공개 중 상태 → 발견 화면에서 작품명 검색 시 결과 1건으로 노출 확인.
- 실제 확인용으로 만든 새 작품과 테스트 주문은 로컬 데모 DB에 남아 있습니다. 초기 시드는 8편, 현재 로컬에는 추가 검증 작품 1편이 있습니다.

## 수정한 문제

- Windows에서 생성 이미지 복사 시 개발 서버의 파일 감시 오류: 데이터·업로드·정적 이미지·원본 에셋을 Vite 감시 대상에서 제외.
- 주문·권한 생성 원자성: SQLite 직렬화 트랜잭션과 PostgreSQL 사용자 행 잠금으로 중복 구매 방지.
- 외부 폰트 의존: Noto 한글 웹폰트를 패키지에 포함.
- 업로드 소유권: media_files 테이블을 도입하고 본인 파일만 작품/회차에 연결.
- 샘플 영상 표시: 작품 ID 추정 대신 회차 데이터의 is_demo로 시연 영상 여부 구분.
- 심사 시 1화부터 연속된 회차인지 검사.
- 다른 로컬 Vite 프로젝트와 HMR 포트가 충돌하지 않도록 숏핑 전용 포트 5174 사용. API 테스트에서는 HMR 비활성화.
- 개발 중 엔트리 모듈이 갱신될 때 React root를 재사용하여 중복 초기화 경고 방지.

## 미검증 및 후속 범위

실제 RDS/PostgreSQL 서버, Docker 이미지 실행, AWS 인프라, 네이티브 Android/iOS 빌드, 실제 기기, OAuth 공급자, 실결제/환불, S3/HLS/DRM, 부하 테스트는 검증하지 않았습니다. Docker CLI는 있으나 현재 Docker 데몬이 실행 중이지 않았습니다. CI 설정은 작성했으나 GitHub 원격 실행은 아직 하지 않았습니다. 현재 검증 결과를 실서비스 출시 승인으로 해석하지 않습니다.
