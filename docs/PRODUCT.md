# 숏핑 제품 및 프로세스

## 참고

2026-09-18 기준 https://www.vigloo.com/ko 와 https://www.dramabox.com/ko 의 공개 페이지를 참고했습니다. 장르 탐색, 인기 순위, 신작, 무료 시작, 회차 단위의 몰입, 멤버십 안내, 모바일 중심 구성을 숏핑에 맞게 재구성했습니다. 타 서비스의 이미지·작품명·로고·독점 영상은 복제하지 않습니다. 로그인 후의 비공개 결제·운영 프로세스를 확인했다고 주장하지 않습니다.

## 시청 흐름

홈 (추천·인기·신작·완결) → 장르·검색 → 작품 상세 → 무료 회차 → 잠긴 회차 → 개별 작품 소장 또는 30일 숏핑 패스 → 시청 권한 검사 → 영상 → 다음 회차.

- 비회원도 무료 회차 시청. 찜·시청 기록·구매는 로그인 필요.
- 구매 금액은 서버의 작품 가격을 기준으로 산출. 클라이언트 금액은 사용하지 않음.
- 주문과 권한은 단일 DB 트랜잭션. 중복 키와 중복 소장을 차단.
- 구독 만료 여부를 API 요청마다 확인. 프런트엔드의 잠금 표시만으로 접근을 통제하지 않음.
- 영상은 `/api/play/:id/:number`에서 권한 검사 후 HTTP Range 지원으로 제공.
- 7초 간격 및 일시정지·회차 이동 시 시청 위치를 저장. 다시 시청하면 최근 위치 복구.
- 구독 종료 후에도 별도로 구매한 작품의 접근 권한 유지.

## 콘텐츠 흐름

PD 작성 → draft → 회차 파일 등록 → pending → 관리자 영상·메타데이터 검토 → published 또는 rejected → 수정 → 재심사.

- 최소 1개의 영상 회차가 있어야 제출 가능.
- 심사 대기 또는 공개된 작품의 직접 수정 금지. 이후 운영 단계에서 공개 작품 개정판·철회 기능을 별도로 확장할 수 있음.
- 반려는 사유 필수. 관리자 심사·회원 관리 작업을 감사 로그에 기록.
- PD는 본인 작품과 본인 업로드 파일만 사용 가능. 타 PD의 파일 URL을 알더라도 연결 불가.
- MP4·JPEG·PNG·WEBP만 허용하고 파일 헤더를 확인. 파일명은 임의 UUID.
- 회원 가입은 시청자만 가능. PD·관리자 승격은 슈퍼관리자만 가능.

## 디자인

- 모바일 100% 폭, PC 중앙 620px. 왼쪽 브랜드 메시지·포스터와 오른쪽 앱 설치 영역.
- 짙은 네이비 `#111519`, 라임 `#c4f562`, 한글 Noto Sans/Serif 로컬 글꼴.
- 번개·플레이를 조합한 숏핑 SVG 로고, Lucide 선형 아이콘의 두께·크기 통일.
- 포스터마다 장르에 맞춘 제목 조판. 텍스트는 별도 레이어여서 변경·번역·접근성 대응이 용이.
- 역할별 같은 색상·버튼·모달·폼 시스템 사용.

## 데이터

users, sessions, dramas, episodes, favorites, history, orders, entitlements, subscriptions, audit_logs, media_files. UUID와 ISO UTC 문자열·정수 화폐 단위를 사용하며 SQLite 전용 비즈니스 SQL을 피했습니다. 운영 PostgreSQL 연결은 `pg` 어댑터로 전환합니다. 스키마 생성은 멱등적이며 후속 컬럼 변경은 버전별 마이그레이션 추가가 필요합니다.
