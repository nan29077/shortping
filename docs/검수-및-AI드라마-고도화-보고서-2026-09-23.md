# 숏핑 전체 검수 + AI 드라마 고도화 제안 보고서 (2026-09-23)

코드는 한 줄도 고치지 않았습니다. 개발은 대표님 지시 후 진행합니다.

- **검수 대상**: 로컬 작업본 `E:\프로젝트\숏핑`(커밋 `79eeafe` + 미커밋 변경 43개 파일, 약 3만 8천 줄)
- **검수 방법**: 영역 5개를 나눠 코드 전체를 읽고, 화면의 API 호출을 서버 zod 스키마와 대조했습니다. 의심 항목은 복사본에서 스크립트로 재현했습니다. 자동 검사도 다시 돌렸습니다.
- **제외 항목**: 9-22 보고서에서 이미 고친 항목은 다시 적지 않았습니다.

테스트는 모두 통과합니다. 새로 찾은 문제는 대부분 테스트가 다루지 않는 영역에 있습니다.

- PostgreSQL 동시 요청
- 실제 공급사의 일시 오류
- 모바일 앱 패키징
- 화면 상태 전환

**가장 급한 것은 3가지입니다.**

1. **돈 관련 경합.** PostgreSQL로 옮기면 작품 전체 열기 이중 청구와 출금 이중 지급이 생깁니다. 구독 매출 배분은 조작할 수 있습니다.
2. **모바일 앱(Capacitor)이 서버에 연결되지 않습니다.** 설치하면 첫 화면부터 "서버에 연결하지 못했어요"가 나옵니다.
3. **AI 제작의 원가 누수와 멈춤.** 영상 결과를 확인하다 일시 오류가 한 번 나면 같은 영상을 다시 생성합니다(원가 2~3배). 한 공급사 대기열이 밀리면 모든 PD의 작업이 멈춥니다.

### 1-3. 낮음 (묶어서 처리 권장)

- **서버**
  - 기간 형식이 `2025-13`도 통과합니다.
  - PD 대시보드 주문에 구매자 `user_id`와 멱등키가 노출됩니다.
  - 설정 캐시가 서버 여러 대에서 무효화되지 않습니다.
  - 분할 업로드 영상은 정리 대상에서 빠집니다.
  - ffmpeg 오류 원문(서버 경로)이 노출됩니다.
  - 충전 멱등키로 동시 요청하면 500이 납니다.
- **AI**
  - 재시작 복구 때 `started_at`을 초기화하지 않아 바로 시간 초과로 처리됩니다.
  - `tick` 실행이 겹쳐 동시 작업 한도를 넘을 수 있습니다.
  - SSRF 검사가 `[::ffff:127.0.0.1]`과 `localhost.`를 통과시킵니다. 다른 도메인으로 리다이렉트될 때 사용자 정의 키 헤더가 따라갑니다.
  - PG에서 공급사 월 예산 컬럼이 INTEGER라 21억 원을 넘으면 오류가 납니다.
  - 합성이나 결과 반영이 실패하면 파일이 남습니다.
  - 대사에 빈 줄이 있으면 VTT가 깨집니다.
- **화면**
  - 공유 링크가 404일 때 JSON 원문이 보이고, 공유 이미지가 모든 작품에서 똑같습니다.
  - 히어로 번호가 `%3`으로 고정되어 있습니다.
  - 영상 Range 요청이 API 요청 제한에 포함됩니다.
  - 영상 오류 문구가 시청자에게 맞지 않습니다.
  - 로그인 뒤 보던 회차로 돌아가지 않습니다.
  - iPhone 노치 상단 여백이 없습니다.
  - 문의 글자 수 검사가 서버와 다릅니다.
  - 핑 화면 오류에 다시 시도 버튼이 없습니다.
  - `aria-current`와 `aria-pressed`가 빠져 있습니다.
- **관리자 · PD**
  - 정산 월 필터가 PD별 표에는 적용되지 않습니다.
  - 출금 통계가 최근 200건 기준이고 라마 전환이 섞입니다.
  - 모델 시험 실행의 폴링이 정리되지 않고 연타할 수 있습니다.
  - 되돌리기 어려운 작업에 확인 창이 없습니다: 공급사 삭제, 권한 변경, 회수, 카테고리 삭제, 인물·컷 삭제.
  - 월 마감 결과 문구가 바로 덮입니다.
  - 주문 내역에서 라마 충전이 '숏핑 패스'로 표시됩니다.
  - 메인페이지 설정을 불러오지 못해도 기본값으로 저장할 수 있습니다.
  - AI 포스터가 끝나면 포스터 후보가 사라집니다.
- **AI 스튜디오**
  - 컷 편집기 `key`에 필드가 빠져 있습니다.
  - 예상 비용을 2초마다 다시 요청합니다.
  - '실패 이유 보기'에 예외 처리가 없습니다.
  - 프로젝트가 주소(URL)에 없어 새로고침이나 뒤로가기를 하면 스튜디오 밖으로 나갑니다.
  - '컷 추가'의 기본값이 영어 "New shot"이라 그대로 라마가 쓰입니다.
  - 합성 버튼이 비활성인 이유가 나오지 않습니다.
  - 내보낸 프로젝트가 '제작 중' 필터에서 빠집니다.
  - 버전 목록을 최근 500개까지만 가져옵니다.

### 1-4. 이상 없었던 영역

- **API 대조**: 화면의 API 호출 전체가 경로, 메서드, 바디 형식에서 서버 zod 스키마와 일치합니다.
- **SQL 호환**: SQLite와 PostgreSQL 사이에 문법 호환 문제가 없습니다.
- **핑·라마 장부**: 로트 차감 순서가 맞고 지갑과 장부 합계가 일치합니다.
- **원천징수 계산**: 3.3% 절사 계산에 오차가 없습니다.
- **라마 예약·차감·반환**: 모든 경로에서 이중 차감이나 이중 반환이 없습니다.
- **소유권(IDOR)**: 프로젝트, 인물, 컷, 버전, 미디어 모두 검사합니다.
- **보안**: 경로 탐색과 XSS 방어가 되어 있습니다. API 키는 AES-GCM으로 보관합니다.
- **LLM 결과 처리**: 결과를 스키마로 검증하고 금칙어를 검사합니다.

## 2. AI 드라마 기능 현황

**진입 경로**: PD 메뉴 → 숏핑 스튜디오 → AI 드라마 제작 → 약관 동의 → 프로젝트 → **작업 공간 7개 탭**(기획·인물·대본·스토리보드·영상·음성·완성)

**AI 기능 5종**: 글(text), 이미지, 영상, 음성 합성(TTS), 음성 인식(STT). **음악과 효과음 기능은 없습니다.**

**공급사**: 16곳 프리셋(중국 포함). 모델 ID는 참고값이므로 실제 키를 넣을 때 최신 모델로 교체해야 합니다.

| 단계 | 지금 되는 것 | 부족한 점 |
| --- | --- | --- |
| 기획 | 템플릿 18종, 스타일 8종, AI 기획안(제목·줄거리·인물·회차 요약) | 세계관, 말투, 복선을 담은 **작품 설정집이 없습니다**. 기획안을 다시 만들면 덮어씁니다. 서버 장르가 5개뿐입니다 |
| 인물 | 최대 8명, 기준 이미지 1장, 목소리 샘플 | **인물 이미지가 1장뿐**입니다. 컷 이미지에는 말하는 사람만 참고로 넘기고, 영상에는 인물 참고가 없어 **얼굴이 컷마다 달라집니다**. 목소리는 공급사 ID를 직접 입력해야 합니다. 외모는 영어로 입력해야 합니다 |
| 대본 | 회차별 AI 대본(최대 40컷), 컷 편집, 컷 하나만 AI로 고치기 | **다시 쓰면 기존 컷이 전부 삭제**되고 버전 기록이 없습니다. 전체 시나리오 보기가 없습니다. 이전 화는 요약 한 줄만 참고합니다. 훅·반전 설계를 돕는 기능이 없습니다 |
| 스토리보드 | 컷 이미지 개별·일괄 생성, 버전 선택 | 시드 고정과 부분 수정이 없습니다. 타임라인 보기가 없습니다 |
| 영상 | 이미지에서 영상 생성(개별·일괄) | 카메라 지시가 글 한 줄뿐입니다. **입 모양 맞추기(립싱크)가 없습니다**. 첫·끝 장면을 지정할 수 없습니다 |
| 음성 | 대사 TTS 개별·일괄 | 감정·속도 지시가 없습니다. 내레이션이 없습니다 |
| 자막 | 합성할 때 자동으로 VTT 생성 | 편집, 스타일, 위치 조정이 없습니다 |
| 합성 | 720×1280 MP4, 이미지 컷은 천천히 확대 | **배경음악·효과음·장면 전환 효과가 없습니다**. 진행률이 없습니다. 영상 원래 소리를 버립니다 |
| 포스터·썸네일 | AI 포스터(글자 없음), 기존 이미지 중 선택 | **제목 글자를 넣을 수 없습니다**. 후보 비교, A/B 테스트, 회차별 썸네일, 공유용 크기가 없습니다 |
| 내보내기·공개 | 작품으로 내보내기, 검수 신청 | 제목·소개·해시태그를 AI로 만들 수 없습니다. **공개한 뒤 다음 화를 추가할 수 없어 연재가 불가능합니다**. 예고편이 없습니다 |
| 자동 제작 | 기획부터 합성까지 빈 곳을 채움, 라마 한도 안에서 실행 | 기획 탭 안에 접혀 있어 잘 보이지 않습니다. 멈춰도 알림이 없습니다 |

**업로더 PD가 겪는 불편**

- **클릭과 화면이 많습니다.** 1화를 만드는 데 약 20번 클릭하고 화면 7개를 거칩니다. 단계마다 결과를 기다려야 합니다.
- **입력과 용어가 어렵습니다.** "화면 묘사(영어)", "외모(영어 권장)", "목소리 ID(공급사 음성 이름)"처럼 영어나 전문 용어를 요구합니다.
- **저장이 제각각입니다.** 칸마다 '저장' 버튼이 따로 있고, 저장하지 않으면 AI 버튼이 비활성입니다.
- **진행 상황이 보이지 않습니다.** 남은 시간, 합성 진행률, 폰에서 볼 수 있는 실패 사유가 없습니다.
- **미리보기와 합성본이 다릅니다.** 미리보기는 무료이고 합성은 따로 해야 해서 헷갈립니다. 소리도 서로 다릅니다.

## 3. AI 드라마 고도화 제안

방향은 **"한 줄 아이디어 → AI가 초안 1화를 완성 → PD는 고칠 곳만 고친다"**입니다. 모든 입력은 한국어로 받고, 영어 프롬프트 변환은 서버가 맡습니다.

### 3-1. 편의성 (PD 작업 흐름 재설계)

1. **'빠른 제작' 시작 화면**
   - 입력: 아이디어 한 줄, 장르, 회차 수, 회차 길이, 품질(초안·표준·고급), 최대 라마
   - 버튼 하나로 자동 제작을 시작하고, 끝나면 **검토 화면**으로 들어갑니다.
   - 지금의 7개 탭은 '세부 편집'으로 둡니다.
2. **탭을 7개에서 4개로 통합**
   - ① 기획·설정(작품 설정집, 인물)
   - ② 대본
   - ③ 장면 편집: 이미지, 영상, 음성, 자막을 **컷 타임라인 하나**에서 다룹니다.
   - ④ 완성·공개: 합성, 썸네일, 소개글, 공개
3. **입력 방식 개선**
   - 한국어 입력으로 통일합니다(화면 묘사, 외모 등).
   - 입력하면 자동으로 저장합니다. '저장' 버튼은 없앱니다.
4. **목소리 라이브러리**
   - 성별, 나이대, 톤으로 필터하고 미리 들어 본 뒤 고릅니다.
   - 공급사 ID는 직접 입력하지 않습니다.
5. **진행과 알림**
   - 작업마다 예상 남은 시간과 합성 진행률을 보여 줍니다.
   - 완료, 멈춤, 실패를 알립니다(앱 푸시와 인앱 알림함).
   - 폰에서도 실패 사유와 '다시' 버튼을 볼 수 있게 합니다.
6. **주소 연결**: 프로젝트를 주소(URL)에 넣어 새로고침이나 뒤로가기를 해도 유지되게 합니다.
7. **비용을 아끼는 흐름**: "초안 품질로 전체를 만들어 본 뒤, 마음에 드는 컷만 고급으로 다시 만들기"를 버튼 하나로 제공합니다. 단계별 예산 한도도 둡니다.

### 3-2. 시나리오 작성

1. **작품 설정집(시리즈 바이블)**
   - 담는 내용: 세계관, 인물 관계도, 인물별 말투, 금기 사항, 복선·떡밥 목록
   - 모든 대본 생성에 자동으로 반영합니다.
2. **시즌 설계**
   - 전체 회차의 흐름(발단, 전개, 반전, 결말)을 설계합니다.
   - 회차마다 **첫 3초 훅과 끝 장면 클리프행어**를 설계합니다.
   - **유료로 전환할 회차를 추천**합니다. 숏폼 드라마 수익 구조에 맞춘 기능입니다.
3. **대본 편집기**
   - 전체 대본을 대본 형식으로 봅니다.
   - 버전을 기록하고 비교하고 되돌릴 수 있습니다. 다시 써도 이전 버전이 남습니다.
   - 선택한 구간만 다시 쓸 수 있습니다.
   - 톤을 조절하는 칩을 둡니다: 더 자극적으로, 더 코믹하게, 대사 줄이기.
4. **대본 진단**
   - 점검 항목: 훅 강도, 전개 속도, 컷당 대사량과 길이 균형, 금칙어·실존 인물
   - 결과는 점수와 고칠 곳 제안으로 보여 줍니다.
5. **원작 각색**: PD가 쓴 시놉시스나 웹소설 원고를 올리면 회차와 컷으로 나눠 줍니다.

### 3-3. 영상 제작

1. **인물 일관성**
   - 인물마다 **레퍼런스 시트**를 만듭니다: 정면, 측면, 전신, 표정 3종, 의상 세트.
   - 컷에 **등장인물 여러 명**을 지정하고, 이미지와 영상 생성에 모두 레퍼런스를 넘깁니다.
   - 장소(로케이션) 레퍼런스도 추가합니다.
2. **연출 제어**
   - 카메라 프리셋 칩: 클로즈업, 푸시인, 패닝, 핸드헬드
   - 첫·끝 장면 지정, 시드 고정
   - 이미지 부분 수정: 이 부분만 다시 그리기
3. **립싱크와 소리**
   - 대사 TTS에 맞춰 입 모양을 맞춥니다(립싱크 모델). 영상 모델이 만든 대사와 효과음은 살립니다.
   - TTS에 감정과 속도를 지시할 수 있게 하고, 내레이션을 추가합니다.
4. **배경음악·효과음(새 AI 종류 `music` · `sfx`)**
   - 장면 분위기에 맞춰 자동으로 추천하고 생성합니다.
   - 대사가 나올 때 음악 볼륨을 자동으로 줄입니다(덕킹).
5. **타임라인 편집기**
   - 컷 길이를 드래그로 조절합니다.
   - 장면 전환 효과를 넣습니다.
   - 자막 편집, 스타일, 위치를 조정합니다(숏폼용 큰 자막 템플릿 포함).
   - 인트로·엔딩 카드와 "다음 화 예고"를 자동으로 붙입니다.
6. **합성 워커 분리**
   - 웹 서버와 합성을 분리해 여러 합성이 동시에 돌 때 서비스가 느려지지 않게 합니다.
   - 진행률을 보여 줍니다.
   - 필요하면 1080p로 출력합니다.

### 3-4. 썸네일 · 홍보 · 공개

1. **썸네일 스튜디오**
   - AI가 후보 4장을 만들고, **한글 제목 글자를 합성**합니다(템플릿과 폰트 선택).
   - 9:16 포스터에서 1:1과 16:9 공유용 크기를 자동으로 만듭니다.
   - 회차별 썸네일도 만듭니다.
2. **썸네일 A/B 테스트**: 숏핑 노출 데이터로 후보별 클릭률을 비교하고 이긴 후보로 자동 교체합니다.
3. **메타데이터 AI**: 작품 제목 후보, 소개글, 해시태그, 회차 제목을 만듭니다.
4. **예고편·티저 자동 편집**
   - 하이라이트 컷으로 15~30초 영상을 만듭니다.
   - 작품별 공유 카드(`og:image`)에 연결합니다.
5. **연재형 공개**: 공개한 작품에 다음 회차를 추가로 내보내고 검수받을 수 있게 합니다. 예약 공개도 추가합니다.
6. **(선택) 번역 자막과 더빙**: 해외 공개용입니다.

### 3-5. 법규 · 안전

- 「인공지능기본법」이 2026년 1월 22일 시행되어 생성형 AI 결과물 표시(워터마크 등) 의무가 생겼습니다. 현재 계도 기간이라고 보도되었습니다.
- 숏핑은 'AI 제작' 표시는 이미 하고 있습니다. 여기에 두 가지를 추가할 것을 권합니다.
  - 합성 영상에 **보이지 않는 워터마크와 메타데이터**를 넣습니다.
  - 첫 화면에 표시 문구를 넣습니다.
- 실존 인물 얼굴을 쓰지 못하게 검사하고, 목소리 복제는 본인 동의가 있을 때만 허용하는 정책도 함께 두는 것을 권합니다.
- 정확한 의무 범위는 법률 검토가 필요합니다.
