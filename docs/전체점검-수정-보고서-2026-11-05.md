## 3. AI 제작 서버 (9건)

| 등급 | 내용 |
|---|---|
| 중요 | 빠른 제작 중 DB 오류가 처리되지 않은 거부로 이어져 **서버 프로세스가 멈출 수 있던** 문제. |
| 중요 | 팀원이 `budgetOk`를 보내 소유자가 정한 프로젝트 라마 예산을 건너뛸 수 있던 문제(AI 조수 포함). 이제 예산 넘김 확인은 소유자만 할 수 있다. 팀원에게는 소유자에게 요청하라는 안내가 나온다. |
| 중요 | AI 작업이 진행 중인 회차를 '회차 수 줄이기'로 지워 라마만 쓰이던 문제 → 작업이 끝난 뒤 줄이도록 막는다. |
| 보통 | 재시도가 공급사 월 한도에 걸리면 정상 실패 처리가 되돌려져 임시 파일이 남던 문제. |
| 보통 | 관리자가 AI를 중단하거나 모델 · 공급사를 꺼도 이미 대기 중인 작업은 계속 공급사로 보내지던 문제. 결과를 기다리던 작업은 원가가 들었으므로 계속 받는다. |
| 보통 | 다른 처리기가 이어받은 작업에 예전 처리기의 늦은 결과 · 실패가 반영되던 문제. |
| 낮음 | 자막용 음성 추출이 실패하면 반쯤 써진 파일이 남던 문제. 예고편 기록 실패 시 영상 파일이 남던 문제. 지워진 작업 행 때문에 처리 주기가 멈추던 문제. |

| 낮음 | 방송국 카테고리 · 초대 링크 · 의견이 확인 없이 삭제되던 문제 → 확인 창을 띄운다. |
| 낮음 | AI 조수에게 보내는 동안 이어서 적은 글이 지워지던 문제. |

## 6. 독립 검토에서 추가로 고친 것 (6건)

- **출금 · 라마 전환 409 오류**: PostgreSQL에서 조회와 묶기 사이에 새 정산이 확정되면 엉뚱한 409가 나던 문제 → 실제로 묶인 건 기준으로 다시 계산한다.
- **탈퇴 PD 방송국 저장**: 이미 추천돼 있던 방송국은 숨김 상태로도 저장할 수 없던 문제.
- **AI 최후 실패 처리**: 다른 처리기가 이어받은 작업을 이 처리에서도 건드리지 않게 했다.
- **스크롤 위치**: 앞으로 가기에서 스크롤 위치를 잘못 기억하던 문제 → 앱이 직접 복원한다.
- **탈퇴 회원 프로필 사진**: 기본 아바타로만 바꾸고 파일은 남겨 두던 것 → 파일도 지운다.
- **새로 고침 반복**: 브라우저 저장소를 못 쓰는 환경에서 끝없이 새로 고칠 수 있던 문제.
