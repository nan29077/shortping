## 나머지 결함(P2) 수정 결과

1. 썸네일 후보 등록·대표 확정 시 DB 소유권과 실제 파일 존재를 모두 검사합니다.
2. 대사를 다시 쓰면 기존 음성과 립싱크를 함께 무효화합니다.
3. AI 조수 계획 실행 직전에 현재 모델·가격으로 견적을 다시 계산하고 금액이 바뀌면 재확인을 요구합니다.
4. 일괄 업로드 진행 중 회차 번호·제목 등 메타데이터 입력을 잠가 화면 값과 실제 등록값이 달라지지 않게 했습니다.
5. 웹·Android·iOS 공유 링크가 `VITE_PUBLIC_ORIGIN`의 공개 주소를 사용하도록 공통화했습니다.
6. 신작은 실제 공개·생성 시각 기준으로 정렬하고 신작·완결의 전체보기 필터를 URL에 유지합니다.
7. 공통 모달 스택을 적용해 최상단 창만 Escape와 바깥 클릭을 처리합니다. 링크를 포함한 초점 순환과 숨김·비활성 요소 제외도 보완했습니다.
8. 작업 센터는 대기 중 작업에만 취소를 표시하고, 실행 중 작업에는 현재 취소할 수 없다는 정확한 안내를 표시합니다.

## 함께 보완한 심사·계정·UI/UX

- 작품 심사 팝업에 썸네일 후보 미리보기, 포스터·회차 영상 로드 확인과 관리자 확인 절차를 적용했습니다.
- 공개 후 추가 회차 심사도 영상 로드와 직접 확인을 마쳐야 승인할 수 있으며, 서버도 실제 영상 파일을 다시 검사합니다.
- 관리자/PD 심사 대기 수에 작품과 추가 회차를 함께 집계합니다.
- 모바일 관리자 메뉴의 `aria-expanded`가 실제 열림 상태와 일치합니다.
- 방송국 구독과 문의 로그인 후 원래 화면으로 돌아옵니다.
- 일반 업로드 작품에 데모 안내가 잘못 표시되지 않도록 실제 데모 회차에서만 노출합니다.
- 브라우저에서 발견한 `thumbnails` 없는 구버전 상세 응답도 안전하게 빈 후보 목록으로 처리해 심사 팝업이 중단되지 않게 했습니다.
