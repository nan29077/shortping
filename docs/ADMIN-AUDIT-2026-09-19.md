## 설정 기능

- 닉네임, 한 줄 소개(PD는 스튜디오 소개), JPG·PNG·WEBP 사용자 이미지 업로드.
- 3D 블록 토이 기본 아바타 30종 중 하나를 최초에 무작위 배정해 계정에 저장합니다. 사용자는 기본 아바타를 직접 선택하거나 다시 뽑을 수 없으며, 직접 업로드한 이미지가 있으면 그 이미지를 우선합니다.
- 모바일 헤더, PC 계정 카드, 마이페이지, 관리자 사이드바/프로필, 회원 목록에 공통 이미지 적용.
- 다음 회차 자동 이동 저장 및 시청 화면 반영. 잠긴 회차로 자동 이동하지 않습니다.
- 이메일 가입 계정: 현재 비밀번호 확인 후 변경, 다른 세션 만료. 공용 테스트 계정의 비밀번호 변경은 제한.
- 유효 로그인 개수 확인, 다른 기기 로그아웃. 세션 토큰은 클라이언트에 공개하지 않습니다.
- 확인창을 통한 본인 시청 기록 삭제. 찜과 구매 권한 보존.
- 이메일/권한은 표시만 하며 프로필 API로 권한을 바꿀 수 없습니다.

## 브라우저 검수 증거

- PD로 **검수용 · 빛이 머무는 밤**을 등록하고 실제 `public/demo/preview.mp4` 파일 업로드. 완료 후 12초 자동 표시 및 회차 저장 성공.
- 1화 제목을 **첫 번째 밤 · 수정 검수 완료**로 바꾸면서 기존 파일 유지 확인. 2화 **두 번째 밤**은 개발용 샘플로 등록.
- 관리자 팝업에서 1·2화 전환. 1화 영상 `readyState=4`, `duration=12`, 접근 제어된 `/api/play/.../1`에서 로딩.
- 두 회차 재생 준비 확인 + 검토 체크 후 승인 활성화. 승인 후 `#/studio/contents` 유지 및 심사 대기 목록에서 제거 확인.
- 관리자·PD·시청자 계정에 배정된 기본 아바타가 재로그인 후 유지되고, 다른 기본 아바타로 임의 변경하는 API 요청이 거부되는지 통합 테스트로 확인.
- 390×844 모바일 시청자/PD 설정: 문서 너비 385px, 가로 넘침 없음. 검토창 너비 360px, 문서 너비 390px. Escape 닫기 정상.
- 로컬에 검수용 공개 작품 1편이 추가되어 이전 검수 작품 포함 총 10편입니다. 공용 관리자/시청자 아바타는 각각 25번/8번으로 저장했습니다.

## 실행 참고

기본 포트 3033. 아바타 재생성: `node scripts/prepare-avatars.mjs`. 개발 환경은 기존 ffmpeg-static을 사용하며 실행 파일은 FFMPEG_PATH로 지정 가능합니다. Docker 런타임에 FFmpeg 설치 단계를 추가했습니다. 실제 Docker 이미지 실행은 이번에 검증하지 않았습니다. 신규 심사 이력·미디어 메타데이터·프로필 테이블은 서버 시작 시 생성됩니다.
